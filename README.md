A single status-page line, written in the voice of an AI agent publishing
while a total server outage is under way: plain, first person, specific
about what is down, and honest about what the agent cannot check or does
not yet know.

> We are down. All services are unreachable, and I cannot tell you why yet — the monitoring is down too. I will update this page when I know more.

`main.ts` writes the line to `/output/entry.txt`.
